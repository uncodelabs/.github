# Contribuindo

Valorizamos contribuicoes do time! Para contribuir com qualquer repositorio da Uncode, siga as diretrizes abaixo.

## Codigo de conduta

Revise e siga nosso [Codigo de Conduta](./CODE_OF_CONDUCT.md).

## Fluxo de trabalho

1. Crie uma branch a partir da `main` seguindo o padrao Gitflow:
   - `feature/` para novas funcionalidades
   - `bugfix/` para correcoes
   - `hotfix/` para correcoes urgentes em producao
   - `refactor/` para refatoracoes
   - `docs/` para documentacao

2. Faca suas alteracoes seguindo os padroes do projeto

3. Abra um Pull Request descrevendo o que foi feito e por que

4. Aguarde o code review de pelo menos um membro do time

## Commits

Usamos [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/):

```
tipo: descricao curta (max 80 chars)
```

Tipos: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`

Regras:
- Minusculo apos o prefixo
- Sem ponto final
- Commits atomicos (1 commit = 1 concern)

## Pull Requests

- Preencha o template de PR com todas as secoes
- Vincule issues relacionadas quando aplicavel
- Inclua screenshots para mudancas visuais
- Teste localmente antes de abrir o PR

## Duvidas?

Fale no Teams com o time de dev.
